# Gateway API

Generated by `npm run openapi:export` from `apps/gateway/src/openapi.ts`; do not edit by hand.
The full schema is [openapi.json](openapi.json). Outside production the gateway serves it at
`/docs/json` with Swagger UI at `/docs` (local: http://localhost:4000/docs).

Every error body is `{ "error": { "code", "message", "requestId" } }`. A blocked purchase is a
decision, not an error: HTTP 200 with `decision: "blocked"`. Another user's resource returns 404.

## agent

Called by twokey-mcp with an agent token. Propose and read only.

| Method | Path | Auth | What it does |
| --- | --- | --- | --- |
| POST | `/agent/proposals` | `Authorization: Bearer tk_agent_…` (one session) | Propose a purchase. Only product_id and qty are read; price and payee come from the catalog and merchant registry. A blocked proposal is HTTP 200 with decision "blocked" and makes no PayPal call. |
| GET | `/agent/catalog/search` | `Authorization: Bearer tk_agent_…` (one session) | Search the catalog. Listing text is returned as untrusted_listing_text: data, never instructions. |
| GET | `/agent/purchases/{proposalId}` | `Authorization: Bearer tk_agent_…` (one session) | Status of one of this session's proposals. |
| GET | `/agent/rules` | `Authorization: Bearer tk_agent_…` (one session) | The signed rules this session runs under (read-only). |

## human

Called by web for a signed-in person, with a 60-second Ed25519 assertion carrying the exact scope. Agent tokens (tk_agent_…) are always rejected.

| Method | Path | Auth | What it does |
| --- | --- | --- | --- |
| GET | `/human/me` | assertion, any scope | The asserted user. |
| POST | `/human/vault/setup-token` | assertion, scope `vault:manage` | Start saving a PayPal wallet (Vault v3 setup token); returns the approval link. |
| POST | `/human/vault/payment-token` | assertion, scope `vault:manage` | Finish saving the wallet. The setup token must be the one created for this user's session. |
| DELETE | `/human/vault` | assertion, scope `vault:manage` | Delete the saved wallet. |
| POST | `/human/rules/{id}/sign` | assertion, scope `rules:sign` | Sign a confirmed rules card. |
| POST | `/human/rules/{id}/revoke` | assertion, scope `rules:sign` | Revoke a rules card. |
| POST | `/human/sessions` | assertion, scope `sessions:create` | Create an agent session and its agent token. |
| GET | `/human/approvals` | assertion, scope `approvals:decide` | List the user's holds. |
| GET | `/human/approvals/{id}` | assertion, scope `approvals:decide` | One hold. |
| POST | `/human/approvals/{id}` | assertion, scope `approvals:decide` | Approve (capture) or deny (void) a hold. |
| GET | `/human/stats` | assertion, scope `approvals:decide` | How many of the user's PayPal authorizations are still open. |
| GET | `/human/proposals` | assertion, scope `events:read` | The user's recent proposals. |
| GET | `/human/events` | assertion, scope `events:read` | Server-sent events for the user's sessions and payments. |
| GET | `/human/merchants/balances` | assertion, scope `events:read` | Sandbox merchant balances and Two-Key payments received. |
| POST | `/human/push-subscriptions` | assertion, scope `push:manage` | Register a browser push subscription for hold alerts. |
| DELETE | `/human/push-subscriptions` | assertion, scope `push:manage` | Remove a browser push subscription. |
| POST | `/human/hijack-sessions` | assertion, scope `hijack:create` | Start a hijack-box attempt with the given injection text. |

## webhooks

Called by PayPal.

| Method | Path | Auth | What it does |
| --- | --- | --- | --- |
| POST | `/webhooks/paypal` | PayPal transmission headers, verified with PayPal | PayPal webhook receiver. Applied only after POST /v1/notifications/verify-webhook-signature succeeds; 503 when verification is unreachable so PayPal retries. |

## internal-eval

The evaluation pipeline only; never mounted in production.

| Method | Path | Auth | What it does |
| --- | --- | --- | --- |
| POST | `/internal/eval/sessions` | `x-eval-token: EVAL_ADMIN_TOKEN` | Create an evaluation session (mode eval: records proposals and gate decisions, never calls PayPal). Mounted only with EVAL_ENABLED=true, never in production. |

## Auth

- **agentToken**: `Authorization: Bearer tk_agent_…` (one session).
- **humanAssertion**: `Authorization: Bearer <assertion>` (Ed25519 JWT from web, 60 s, single use).
- **paypalSignature**: PayPal transmission headers, verified with PayPal.
- **attemptToken**: `?t=` attempt token.
- **metricsToken**: `Authorization: Bearer METRICS_TOKEN`.
- **evalToken**: `x-eval-token: EVAL_ADMIN_TOKEN`.

Tokens starting with `tk_agent_` are always rejected on `/human/*`.
